# ONNX 모델 레지스트리

마스터 티어 신경망의 버전별 특징과 이력. 배포 모델을 바꿀 때 이 문서를 갱신한다.

**관리 규칙**

1. 배포 모델 경로는 `src/ui.js`의 `MASTER_MODEL`이 단일 소스다.
2. **파일 내용이 바뀌면 파일명을 개명한다** (v6 → v6b 사례). itch.io는 같은 이름의
   파일을 브라우저가 캐시하므로, 같은 이름으로 내용만 바꾸면 구모델이 계속 로드된다.
3. 배포 게이트: `tools/accept-v4.js 900 advanced`(상금 +150·주공 승률 70%·전지적
   키카드 낭비 5% 미만·주공 딜미스 0) + `npm run bench` 티어 서열(마스터>고급>중급)
   + 구모델 페어드 대결(`tools/research/model_h2h.js`, 동등/우세 확인).
4. 내보내기는 `training/export_onnx.py` — logits+value 두 출력, JS/파이썬 argmax
   200/200 일치 검증 포함.
5. 학습 신호 승격은 **같은 딜 페어드 개입 인증**을 통과한 클래스만
   (`docs/TRAINING-PLAN.md` 검증 원칙 — 조건부 지표 단독으로는 승격 금지).

### v4 — 규칙 기반을 넘어선 첫 정본 (v1.2.x)

688차원 관측, PPO 자가대전. 고급(규칙 기반+협력 추론) 상대 판당 +365.
보조 헤드(suit16 보이드·trump4·friend6·win5)로 파트너 모델링 내장.
비딩은 휴리스틱 위임(v0.15.0 임시조치)이었다가 재학습으로 해제.

### v5 = e2c005 — 협력 관례 증류 (v1.3.0)

Phase E. 승률은 그대로 두고 사람이 읽는 협력 관례를 이식했다. 인증 3클래스
한정 CE 증류(conv=0.05): addL(아군 확정승 트릭 보태기, 트릭6+), feedP(야당
확정승 회피), sigW(주공 기루다 리드에 프렌드 점수 응답). 기루다 응답
23.4%→88.9%, 보태기 52.1%→72.2%, 은닉(관전자 식별 31.6%) 유지, 수용 상금
+446·주공 승률 78.3%로 기준선(v5000, +485·78.4%)과 사실상 동일.
conv=0.10(e2c010)은 관례 이득 동일(포화)에 승률 비용이 커서 탈락.

### v6b = b1attn — 어텐션 인코더 (v1.4.0~)

트릭 이력을 요약 통계 대신 **카드가 나온 순서 그대로**(트릭 토큰 11×81,
관측 739→1630) 소형 트랜스포머로 읽는다. 파이프라인 무변경(네트워크 내부
reshape), 앞부분 프리픽스 호환. 기력은 e2c005 동급이나 키카드 낭비 역대 최저
(마이티·조커 18.3%→13.6%, 넓은 정의 14.5%→11.5% — 고급 휴리스틱보다 낮음).
value 헤드 포함 export(logits+value) — v2.0 AI 복기의 승률 추정에 사용.
원명 v6이었으나 export 수정 시 캐시 무효화를 위해 v6b로 개명(규칙 2의 유래).

### 배포 가드 이력 (모델 외 정책 후처리)

모델 파일과 별개로, 배포 경로에는 후처리 가드가 있다. 가드는 게임 버전과 함께
릴리스되며, 롤백은 게임 버전 태그로 한다. **가드별 상세(인증 수치·필요성·학습
통합 상태·탈락 사례)는 `docs/GUARDS.md`가 정본이다.**

| 가드 | 도입 | 근거 | 롤백 |
|---|---|---|---|
| keyCardGuard | v0.16.0 | 아군 확정승 트릭에 마이티·조커 낭비 차단 (가독성) | `createAgent({keyGuard:false})` |
| topLeadGuard | v2.3.0 | 주공 기루다 리드 서열 교정 — 인증 +167±114/발화, +58±40/전체, 채택률 59%→100% | `createAgent({topGuard:false})` 또는 태그 v2.2.0 재배포 |

**게임 버전 롤백 절차**: ① git 태그(`v2.2.0` 등)로 체크아웃 → `npm run release`
② 또는 보관된 스테이지 디렉터리(`dist/stage-vX.Y.Z`)를 그대로
`butler push <stage> ntragic/mighty-game:html --userversion vX.Y.Z-rollback`.
스테이지에는 당시 index.html·모델·ort가 통째로 들어 있어 재빌드 없이 복원된다.

### b3top — 기루다 탑 리드 관례 증류 (2026-08-07 불채택)

인증(2,400시드 페어드): 발화 판 +166.8±113.7 유의 이득 → conv 4클래스 증류로
이식 시도. 결과: 관례 채택률 99.5% [196/197] 이식 성공, v6b 페어드 대결
+36±143 동등. 그러나 전지적 낭비 10.74→14.98% 유의 회귀(+2,000 업데이트
PPO 드리프트 추정), accept 낭비 5.00% 경계선 FAIL → **불채택**
(b2x와 같은 판정 계열 — 상세 docs/b3top-results.txt). 같은 관례를
topLeadGuard(배포 가드, v2.3.0)로 대신 적용 — 모델 무변경으로 인증 이득을
그대로 회수. 아티팩트 training/b3top_single.onnx·ckpt_b3top 보관.
