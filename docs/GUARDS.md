# 배포 가드 관리 문서

최초 릴리즈 신경망(v0.11.0, `mighty_master.onnx`) 이후 배포 경로에 추가된
후처리 가드의 목록과 근거, 학습 통합 상태. 가드를 추가·제거·모델에 통합할 때
이 문서를 갱신한다. 모델 파일 이력은 `docs/MODELS.md`, 인증 방법론은
`docs/TRAINING-PLAN.md` 검증 원칙 참조.

**가드란**: 신경망 argmax 이후에 적용되는 규칙 기반 교정. 모든 정책 노출 표면
(실플레이 에이전트·코칭·AI 복기 시뮬)이 같은 최종 경로를 재사용한다 —
`chooseAction → actionToEngine → keyCardGuard → topLeadGuard`.

**승격 관문**: 같은 딜 페어드 개입 실험에서 유의 이득(또는 무해 확정 + 명백한
가독성 이득)일 때만 배포한다. 조건부 지표·직관·단일 국면 실측만으로는 승격
금지 — 아래 "탈락 사례"가 이 관문이 실제로 막아낸 목록이다.

## 현행 가드 (6건)

|---|---|---|---|---|---|
| keyCardGuard | v0.16.0 | 아군 가시확정승 트릭에 마이티·조커·기루다 낭비 / 못 이기는 트릭에 비싼 카드 | 승률 중립 (설계상 무해 — 확정승 트릭 한정) | 가독성: "어이없는 낭비" 차단. 가드ON이 낭비 13.6%→OFF 14.2%+넓은 17.5% | 미통합 — v4·v6 재학습으로 자체 낭비가 줄었지만(역대 최저 11.5%) 잔여 케이스가 있어 유지 |
| topLeadGuard¹ | v2.3.0 | 주공이 기루다 리드를 골랐고, 내 최고 기루다 위 서열이 미출현이며, 상대 기루다 잔존 → 최고 기루다로 교체 | 발화 판 **+167±114** · 전체 **+58±40** · 승수 +15/645 (2,400시드) | 승률 실이득 + 관례 가독성(채택률 59→100%) + 프렌드 신호 | 증류 시도(b3top): 이식 99.5% 성공했으나 동반 PPO 드리프트로 낭비 회귀 → 모델 통합 불채택, 가드 유지 |
| tfeedGuard¹ | v2.4.0 | 공개 후 야당이, 여당 최강 기루다 리드 트릭에 이기지 못할 점수 기루다를 태움 → 최저 비점수 기루다로 교체 | 발화 판 주공 상금 **−895±446** · 전체 −19.5±11.1 · 여당 승수 −6/40 (2,400시드) | 야당 수비 실이득 — 점수 기루다는 야당이 이기는 트릭에 보태야 함 (실플레이 제보 −942/판 재현) | 미통합 — 앵커 증류 후보 |

| cutGuard | v2.5.1 | 공개 후·보이드·상대팀 최강 점수 트릭·가시 확정승 기루다 컷 존재 → 최저 확정승 컷 | 발화 좌석 상금 **+533±166** (1,600시드, 두 배치 단독 유의) | keyCardGuard의 역방향 — 먹어야 할 때 먹기 (제보 +1,150/판) | **v8에 내재화 완료(v2.6.0)** — 안전망, 발화 0 확인 후 제거 검토 |
| c1Guard | v2.5.0 | 주공이 위 서열 잔존 상태에서 점수 기루다 리드 → 정책 차선으로 교체 | 발화 판 **+213±169** · 승수 +14/299 (v7 기준 2,400시드; v6b 중립 — 모델 전용) | 위 서열에 잡히며 점수 헌납하는 리드 차단 (셀프 리뷰 C1) | 교사 정책 의존 — 가드 유지 |

¹ v7(=b4a)에 내재화 완료 — v2.5.0부터 안전망(발화율 ~0). c1Guard는 v7 전용
인증(v6b에선 중립 +73±172)으로 v2.5.0에서 모델과 함께 도입.

상세:

### keyCardGuard (`src/mighty-ai.js`)

- **필요성**: 자가대전 NN은 결판난 트릭의 카드 가치 차이에 무감(승패 동일 →
  그래디언트 없음). 사람 눈에는 마이티를 아군 조커 위에 얹는 장면이 치명적
  어색함이라 가독성 목적으로 도입.
- **판정은 좌석 가시 정보만** — 미출현 카드 위협 논리. 전지적 판정 아님.
- **롤백**: `createAgent({keyGuard:false})`.
- **모델 통합 전망**: 세대마다 자체 낭비가 줄고 있어(18.3→13.6→11.5%) 언젠가
  제거 검토 가능. 제거 조건: 가드 OFF 낭비가 ON과 통계 동급이 될 때.

### topLeadGuard (`src/mighty-ai.js`)

- **필요성**: NN의 "낮은 기루다 탐색" 습관이 위 서열 부재 상황에서 순손해
  (T=1 학습 대 argmax 배포 격차 + 자가대전 사각). 리드 무늬 선택 자체는 강제
  하지 않음 — 그 변형(any)은 실측 중립(+69±260)으로 미인증.
- **롤백**: `createAgent({topGuard:false})` 또는 태그 v2.2.0 재배포.
- **모델 통합 전망**: 앵커 증류(아래) 1순위 후보 — 이식 자체는 b3top에서
  99.5% 입증됨.

## 모델에 증류돼 가드가 필요 없는 관례 (v5=e2c005부터 내장)

가드가 아니라 학습(인증 클래스 한정 CE, conv=0.05)으로 모델 안에 이식된 것들.

| 관례 | 인증 | 이식 결과 |
|---|---|---|
| addL — 공개 후 여당, 아군 확정승 트릭(트릭4+)에 최저 점수카드 보태기 | −7.3±8.4 / 트릭4~5 확장 −8.8±9.8 (무해) | 보태기 52→72% (v6b 68%) |
| feedP — 공개 후 여당, 야당 확정승 트릭에 점수 회피 | +12.8±19.2 (무해) | 헌납 12.4%로 휴리스틱(13.8%) 추월 |
| sigW — 프렌드가, 주공이 이기고 있는 기루다 리드에 점수 응답 | −4.8±5.9 (무해) | 기루다 응답 23→89% |

마이티 무늬 리드 선택 → 차선 교체. 페어드 인증 후 승격 판단.

## 운영 원칙

1. **추가**: 실플레이 제보 → 클래스 정의(좌석 가시 정보만) → 페어드 개입 인증
   → 유의 이득(또는 무해+명백 가독성)일 때만 가드 구현 → 전 표면 동일 경로
   적용 → 단위 테스트 + 릴리스.
2. **롤백**: 가드별 opts 스위치 + 게임 버전 태그 + dist/stage 보관 3중
   (`docs/MODELS.md` 절차).
3. **모델 통합(앵커 증류)**: 가드가 4~5개에 이르렀으므로 다음 학습 사이클에서 PPO 없이 conv CE + 원본
   KL 앵커만으로 짧게 미세조정해 일괄 통합한다 — b2x·b3top을 죽인 "동반 PPO
   드리프트"를 구조적으로 제거하는 방식. 통합 후 가드는 안전망으로 유지하고
   발화율 0 확인 뒤 제거.
4. **장기**: 리그 학습(NFSP류)으로 자가대전 사각(자기가 안 하는 공격에 무노출)
   자체를 줄인다 — 가드 수요의 근본 원인 제거.
